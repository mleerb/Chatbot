# Safety and validation

- Never print, copy into source files, or commit secrets from `.env` or user documents in `documents/`.
- Keep FastAPI using Deep Agents (`create_deep_agent`), uploaded document context, and optional Langfuse tracing. No terminal interface is required.
- Keep browser uploads in memory and sessions isolated; do not expose this unauthenticated local demo on a public interface.
- Disable live embeddings in offline backend tests with `--env EMBEDDING_MODEL=`; fake-provider tests enable their own model. Large-file page text and search queries go to the configured embedding provider when enabled, including backfill of old files; never silently bypass the configured gateway.
- Document source text must render only as escaped plain text, never HTML or Markdown. Source IDs never grant access: require the active owned conversation, a persisted assistant reference and an existing upload. Bind citations to immutable read-time revision text; keep document `[D1]` and web `[W1]` markers separate and filter unknown/incomplete markers in streamed and stopped answers.
- Generated HTML preview is distinct from citation text: keep its allowlist sanitizer, no-permission iframe sandbox and restrictive CSP; never enable script/same-origin/navigation privileges. Bundle PDF renderer/worker assets locally and do not expose interactive PDF scripts/forms/links. Generated preview endpoints must check active conversation ownership, stored file membership and input/output size limits; downloads remain unchanged.
- Prefer Docker validation: rebuild with `docker compose up -d --build`, run `python -m unittest discover -s tests` in a temporary app container with `tests/` mounted read-only, and smoke-check the running web app. See `docs/setup.md` for exact commands. Host Python environments are optional and are not kept in the cleaned workspace.
